# AI Agent 学习计划与考试检测系统

这是一个面向嵌入式团队 AI Agent 应用工程师的学习与检测站点。

目标是帮助已有 Web / H5 / App / Electron 开发经验的工程师，逐步具备内部 AI Agent 和 AI 提效工具的独立交付能力。

## 当前学习计划

学习周期为 16 周，每个工作日 120 分钟，总投入约 160 小时。

主线采用 FWA 场景，AIoT 和 Tracker 通过适配层扩展：

| 阶段 | 周次 | 学习重点 | 主要产出 |
| --- | --- | --- | --- |
| 工程底座 | W1-W4 | Python、模型网关、SSE、FastAPI、Vue/Electron | 可运行的日志分析与流式问答底座 |
| RAG 与工具 | W5-W8 | 领域建模、混合检索、引用、评测、Function Calling、MCP | 可信 RAG 与只读工具 |
| Agent 治理 | W9-W12 | 显式工作流、LangGraph、HITL、追踪、成本、安全 | 受控诊断 Agent |
| 产品化试点 | W13-W16 | 三产品线适配、CI/CD、部署、试点、交接 | 可交接的内部试点版本 |

### 每日执行节奏

- 10 分钟：回顾昨天的结论和阻塞点
- 30 分钟：官方课程或文档
- 55 分钟：编码与实验
- 15 分钟：测试和验收
- 10 分钟：登记证据、复盘和下一动作

完成学习不能只记录“看过课程”，必须留下代码、测试输出、文档、评测结果或可复核命令。

## 使用考试系统

打开站点后可以使用以下功能：

- 每日任务打卡与证据登记
- W1-W16 周测与重考
- 1/3/7/21 天复习队列
- 能力掌握度与 M1-M4 门禁
- Markdown / JSON 报告导出

题库当前版本为 `3.1`，共 51 题。练习卷不计入掌握度；正式掌握度需要有效打卡、题型覆盖和门禁证据共同满足。

每日提醒链接格式：

```text
https://jiepijiang.github.io/ai-study-exam/index.html?date=2026-09-28&week=1&tab=checkin
```

周测链接格式：

```text
https://jiepijiang.github.io/ai-study-exam/index.html?date=2026-09-28&week=1&tab=exam
```

## 学习闭环推进顺序

```text
多维表格维护每日计划
    -> 飞书定时工作流读取当天记录
    -> 飞书私聊发送当天任务、课程和考试链接
    -> GitHub Pages 完成学习、打卡和周测
    -> 记录任务证据、成绩和复习日期
    -> 回写多维表格
    -> 根据未完成项和复习队列生成下一次提醒
```

### 第一阶段：静态考试站点

当前仓库已经包含题库、考试页面、每日计划 JSON 和深链接能力。页面当前使用浏览器 `localStorage` 保存本地打卡数据，适合先运行和验证流程。

### 第二阶段：连接飞书多维表格

飞书授权完成后，按以下顺序接入：

1. 只读检查目标 Base、表、字段和现有记录。
2. 将个人每日计划、每日任务明细和课程资源目录与表字段映射。
3. 保留原有计划记录，只新增证据版或任务版数据。
4. 增加考试记录和打卡记录，用于成绩、证据和复习日期追踪。

### 第三阶段：每日消息提醒

建议默认时间：

- 工作日 20:20：发送当天学习提醒。
- 工作日 22:35：仅对未完成或未登记证据的任务发送补交提醒。
- 周五完成周测后：发送本周成绩、错题和下周复习项。

消息中包含当天任务、课程入口、GitHub Pages 打卡链接和周测链接。

### 第四阶段：完成自动闭环

当前 GitHub Pages 不保存飞书凭证，也不会直接调用飞书 Open API。正式同步优先采用：

1. GitHub Pages + 飞书多维表单：简单、安全，适合作为 MVP。
2. GitHub Pages + 受控回写 API：支持自动提交成绩和证据，但需要后端完成身份校验、幂等、限流和审计。

不能把 App Secret 放入 GitHub Pages 或浏览器代码。

## 飞书应用说明

飞书应用是本地 CLI / 工作流调用飞书开放 API 的身份和权限入口，负责：

- 读取多维表格计划；
- 发送本人私聊提醒；
- 接收或读取打卡结果；
- 回写任务状态、考试成绩和复习日期。

它不负责运行题库，也不会自动触发其他系统通知。只有明确调用消息接口时才会发送消息。

## 本地开发

静态源文件位于仓库根目录：

```text
index.html
questions.js
question-bank.json
daily-plan.json
site-config.json
```

直接使用任意静态 HTTP 服务运行，例如：

```powershell
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 当前边界

- 飞书授权和多维表同步需要在本机完成飞书应用审批后再启用。
- 当前浏览器打卡数据是本地数据，清除浏览器存储后无法恢复。
- 题库和每日计划是公开静态资源，不包含 App Secret、Cookie、Token 或内部系统凭证。
