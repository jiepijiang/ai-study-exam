# 参考站点功能审计

参考地址：<https://ruankao.dpdns.org/sprint>

本项目在 2026-09-28 使用用户 Edge 的远程调试会话读取已登录页面的可见内容、导航和公开前端资源。审计只记录交互基线，不复制参考站点代码、品牌资源或账号数据。

## 可见模块

- 首页：学习概况、每日一练、错题、分类覆盖率、必考速记。
- 真题：按题型和年份浏览试卷，开始考试和导出 PDF。
- 刷题：按题型、知识点分类练习，显示完成量和正确率。
- 搜题：关键词、题型、年份、难度筛选题库。
- 知识导图：按科目、章节和知识点浏览资料。
- 论文：论文范文、写作模板和提交入口。
- 冲刺：模拟卷、计算题、公式、英语单词、必考速记、易错集锦和答题套路。
- 我的：学习报告、错题本、Anki 背题、收藏夹、笔记、AI 配置、AI 诊断和意见反馈。

## 冲刺子页面

| 页面 | 路径 | 交互 |
| --- | --- | --- |
| 生成模拟卷 | `/sprint/mock-exam` | 年份范围、题型数量、模拟考试/练习模式 |
| 计算题汇总 | `/sprint/calc` | 按类型查看公式、例题和易错点 |
| 英语单词 | `/sprint/words` | 翻卡、认识/不认识、掌握进度 |
| 必考速记 | `/sprint/points` | 分章要点和高频易错知识 |
| 答题套路 | `/sprint/skills` | 案例分析、架构设计、论文写作模板 |
| AI 出题 | `/sprint/ai-questions` | 选择知识点和题量生成练习题 |

## 本项目映射

- 登录/注册/退出：服务端会话、密码哈希和 userId 数据隔离。
- 首页概况：计划进度、打卡、考试、复习和掌握度摘要。
- 题库/刷题/周测：复用当前 `question-bank.json`，服务端判分并追加历史。
- 错题/复习：1/3/7/21 天队列，按用户隔离。
- 报告和笔记：服务端保存，可导出报告；开放题保留人工复核状态。
- 主题：浅色/深色主题切换，桌面侧栏和 H5 底部导航。

## 边界

1. “功能 1:1”按用户可见信息架构和主要交互验收，不复制参考站点代码、账号体系或付费内容。
2. 参考站点的游客按钮可能创建外部临时会话，本次审计未点击该按钮。
3. 未读取 Cookie、密码、Token 或浏览器本地凭证。
4. FWA、AIoT、Tracker 的真实字段和公司内部数据契约仍需内部确认，不能从行业经验直接写入生产接口。
